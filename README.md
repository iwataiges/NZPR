# NZPR
Net-Zero Progress Report

## About this repository

This is a repository to provide input data, python scripts, outputs of the scripts (including charts), manuscripts and other related files of the IGES Net-Zero Progress Report for Japan, 2026.

## Directories and files

charts/ chart PNG files generated by scripts under scripts/
doc/ documents
doc/00proc.md records of script executions
doc/report2026/ manuscript texts and figures
doc/report2026/NZPR.md report manuscript
doc/report2026/NZPR.bib citations in natbib format
inputs/ input files
outputs/ output files generated by scripts under scripts/
scripts/ python scripts
