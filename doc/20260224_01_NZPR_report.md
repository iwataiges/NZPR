#### データソース

日本の温室効果ガス(GHG)排出量は、環境省が発表する「[我が国の温室効果ガス排出量及び吸収量について][MOE20250425]」と国立環境研究所温室効果ガスインベントリオフィスが発表している「[日本の温室効果ガス排出量データ][NIES20250425]」を参照し、後者のエクセルデータ(2025年4月25日発表の2023年度までのデータ, L5-7gas_2025_gioweb_1.0.xlsx)を利用した。

エネルギー消費量は、経済産業省 資源エネルギー庁が発表する「[総合エネルギー統計][METI20250425]」を参照し、総合エネルギー統計簡易表(stte_2023a.xlsx等)を利用した。

## 4. 再エネ拡大の課題と必要な変化

政府審議会での議論、関係団体の提言、JCLP参加企業の議論等をもとに、再エネ拡大の課題と対策をまとめる。

「再エネ設備を増やす」「再エネの最大限活用」を通じて、経済合理性を向上させることが主眼であり、その上で、社会的な受容性を高め、適切な廃棄・リサイクルを行なって、持続可能な発展を実現することが望ましいと考える。

1. 再エネ設備を増やす
- 設置場所の拡大と規制緩和
- 次世代技術の開発・普及
- インセンティブの最適化

2. 再エネの最大限活用

3. 社会的受容性の向上
- 地域裨益の仕組みづくり

4. 廃棄・リサイクル
- 費用積立の義務化
- リサイクルの推進
