# IGES Net-Zero Progress Report

日本の温室効果ガス排出削減の進捗状況と必要な対策の検討

## 1. Introduction

### 目的

- なぜ排出削減が重要か
- 日本が排出削減に取り組む意義
- 定量的な進捗・ギャップの可視化と、そのギャップを生む要因の考察
- 部門ごとの進捗の検討（今回は予備的なものにとどまる）と、1.5CRMのシナリオとの比較を通じた効果的な対策の考察
- 特に重要な、電力脱炭素化における進捗とギャップの考察
- 再エネ導入拡大における課題と必要な対策の検討
- これらによって、気候変動対策、エネルギー政策の検討に資することを目指す


#### IGES 1.5℃ロードマップとの関係
- 1.5℃ロードマップ（バランスシナリオ）と政府目標シナリオ
- 政府目標シナリオは、2021年の第6次エネ基及び2023年時点での政策動向を踏まえ、公表されている目標数値等（排出量だけでなく、エネルギーミックスや再エネ導入量や電動車の導入目標等も含む）をできるだけ反映しつつ、2050年ネットゼロまで直線的に排出が削減されるシナリオとしてパラメータの調整を行なった。第6次エネ基の需給見通し等と厳密に整合していないことと、第7次エネ基で需給見通し作成において参照されたシナリオとは一致していないことに留意する必要がある。（第7次エネ基のRITEによる複数シナリオと政府目標シナリオを比較し、差異をまとめ、参考資料としてつけておくのが良いか）

## 2. Progress toward Net-Zero

### Methods

- GHG全体及びCO2、CH4の日本全体でのネット排出量の推移
- エネルギー消費量、排出原単位（排出係数）及びエネルギー起源CO2排出量について、部門別の実績
- 実績は公開データに基づく。計算および作図に使用したコードや計算結果はgithubで公開する

#### データソース

日本の温室効果ガス（GHG）排出量は、環境省が発表する「[我が国の温室効果ガス排出量及び吸収量について][MOE20250425]」と国立環境研究所温室効果ガスインベントリオフィスが発表している「[日本の温室効果ガス排出量データ][NIES20250425]」を参照し、後者のエクセルデータ（2025年4月25日発表の2023年度までのデータ, L5-7gas_2025_gioweb_1.0.xlsx）を利用した。

エネルギー消費量は、経済産業省 資源エネルギー庁が発表する「[総合エネルギー統計][METI20250425]」を参照し、各年度の総合エネルギー統計表（stte_2023.xlsx等）を利用した。

図[GHGpath1]では、日本全体のGHG排出量、排出・吸収量の実績値と、2030年、2035年、2040年のGHG排出削減目標（2013年度を基準とした削減割合）を示している。
基準となる2013年度の数値は、森林等の吸収量を含まない「排出量」を用いていることに注意が必要である。
2030年度の削減目標（2013年比46%、さらに50%の高みに向け、挑戦を続けていく）のうち46%という数値や、2025年に決定された2035年度、2040年度の目標は、2013年度の基準値から2050年ネットゼロへの「直線的な経路」の上にほぼ乗っている。

これまでの排出削減の実績に基づいて、削減ペースが政府目標に対して十分であるかどうかを吟味する一つの方法として、排出・吸収量の実績を最小二乗法により直線でフィッティングし、その直線を未来に延長してみる。この際、フィッティング範囲として、日本の排出削減目標（国が定める貢献 (Nationally Determined Contribution); NDC）で定められた計算方法のデータが公開されている2014年度から2023年度を使う場合と、直近の5年間である2019年度から2023年度を使う場合の二通りで行なった（2014年度から2023年度を範囲とする場合、COVID-19の影響で世界的に排出量が急減した2020年度は除いている）。これらの直線フィッティングを延長した場合、直線は2030年以降のNDCの各点よりも上を通っている。これは、これまでの排出削減ペースは排出削減目標を達成するには十分ではなく、目標達成のためには、対策の強化によって排出削減ペースを加速することが必要であることを示している。

将来の排出量がどう変化するかの見通しについては、単純にこれまでの延長で進むとは考えられず、社会経済の実体的なアクターである企業等の取組み強化や政策強化等によって、これまでよりも早いペースで排出削減が進む可能性や、人口減少や経済活動の変化による変動がありうる。また、脱炭素化は社会経済活動のあらゆる面で均一に進むわけではなく、費用対効果の高い部分は先行して進むと期待される一方、設備投資等の初期コストが高い対策や、異なる業種の企業など多様なアクターが関与する活動などは変化が進みにくい、といった傾向も考えられる。よって今後の排出削減等の見通しとして、これまでの傾向の単純な外挿は強い根拠をもった指標とは言えない。本レポートでは、これまでの取組みについて、どこが相対的に順調で、どこに遅れがあるか（ボトルネックはどこにあるか）を、シナリオ分析の結果と照らし合わせながら検討するための一つの指標としてこれまでの実績の直線近似を外挿したものを用いる。

![GHG排出量推移2](doc/report2026/figures/20251208_01_plot_GHG_total_IPCC_cap.png)
*図[GHGpath2]: 日本のGHG排出・吸収量の実績とNDCに定められた削減目標、IPCC AR6統合報告書のC1、C3経路（それぞれおおよそ1.5℃経路、2℃経路に相当）を日本の排出量にスケールしたものとの比較*

図[GHGpath2]では、図[GHGpath1]同様に日本全体のGHG排出・吸収量の実績値とGHG排出削減目標を示した上で、IPCC [AR6統合報告書][IPCC_AR6_SYR]で示されたモデル経路を、日本の排出量にスケールしたものを併せて示している。IPCC AR6のモデル経路として、C1 （オーバーシュートしない又は限られたオーバーシュートを伴って温暖化を1.5℃に抑制 （&gt;50%））とC3 （温暖化を2℃に抑制 （&gt;67%））を用いている。日本の排出量へのスケーリングは、2019年度の日本のGHG吸収・排出量（1,131MtCO<sub>2</sub>e）と、IPCC AR6に記載された2019年のグローバルネット排出量推定値（59GtCO<sub>2M/sub>e）の比をとり、C1、C3経路にかけることで行なっている （C1経路は2019年に約55GtCO<sub>2</sub>eとなっており、ネット排出量推定値とずれている）。

この図が示しているのは、日本のNDCで定められた削減目標に基づく2030年から40年のGHG排出・吸収量は、C1経路を定めた母集団となるシナリオ群の中央値（青い線）からは上にずれており、2030年、2035年の点はC1の95%範囲（青いシェード）からもやや上に位置していることである。スケーリングをどのように行うかによって位置関係は多少動くため、日本のNDCの点がC1経路の95%範囲に入るかどうかは議論の余地がある。一方で、日本の削減目標がC1カテゴリーに入るモデルの大半が示す経路よりも大きく上にあるという点には議論の余地はない。

なお、2040年の日本の削減目標（2050年への直線的な削減経路上にある）とC1経路との差は2030年や2035年に比べて小さくなっているが、これはグローバルのC1経路の中央値がGHG排出においては2050年ネットゼロになっていないためである。メタンはCO<sub>2</sub>よりも排出削減が難しいと考えられており、C1経路の中央値はメタンについては21世紀中にネットゼロにはならない。世界全体ではメタンのGHG排出量全体に占める割合は日本に比べて高く、CO<sub>2</sub>の吸収量が排出量を大きく上回って、GHG全体のC1経路がネットゼロとなるのは21世紀後半になっている（IPCC [AR6統合報告書][IPCC_AR6_SYR] SPM Figure SPM.5参照）。多くのC1カテゴリーのモデルで、OECD諸国は世界全体に先んじて2050年またはそれ以前にネットゼロを達成するシナリオが想定されているため、1.5℃目標に日本が貢献できる経路を考える上では、2050年GHGネットゼロは外せない条件と考えられる。IPCC AR6の排出削減経路と日本のGHG排出量やNDCとの関係については[岩田他（2024）][Iwata2024]で詳述している。

#### 政府目標と1.5℃ロードマップが示す排出削減を達成するために必要な削減ペース

![GHG削減ペース](doc/report2026/figures/20260226_03_plot_GHG_total_diff_cap.png)
*図[GHGdiff]: 日本の前年度比GHG削減量の実績と平均値（青い破線）、及び2024年度以降に2030年度、2035年度NDCの削減目標値を達成するために必要な1年あたりの排出削減量（赤いシェード及び赤い点線）、IGES 1.5℃ロードマップ（バランスシナリオ）の2035年排出量を達成するために必要な1年あたりの排出削減量（緑の点線）*

これまでのGHG排出削減の進捗を単純に延長すると、2030年以降の政府目標を達成するには十分ではないことをみてきたが、図[GHGdiff]では、目標を達成するためにはどれくらい削減ペースを加速することが必要かを定量化した。青い棒グラフが2015年度以降の前年度比の排出削減量の実績で、平均すると毎年31.0 MtCO2eを削減してきている。なお、2020年度はCOVID-19の影響で大きくGHG排出量が下がったため、2020年度（2019年度比）と2021年度（2020年度比）のデータは平均から除いている。これに対し、2030年度に2013年度比46から50%の削減を達成するためには、2024年度以降に平均 36.7–44.7 MtCO2e/年の削減が必要であり、2035年度に60%の削減を達成するためには、平均37.9 MtCO2e/年の削減が必要である（これまでの平均の約1.2倍から1.4倍の削減ペースに相当する）。
また、IGES 1.5℃ロードマップ（バランスシナリオ）は、2035年に2013年度比76%の排出削減となる経路であり、平均では今後56.4 MtCO2e/年とこれまでの約1.8倍の削減ペースに相当する。

一般的に、ネットゼロへの移行シナリオにおいては、ある程度排出削減が進行した後は、時間が経過するにつれて排出削減のペースが落ちていく。これは、炭素中立的な社会経済への移行において、費用対効果が高く、相対的に着手しやすい領域から着手されるため、移行の後期になるほど脱炭素化が難しい領域に取り組むことが必要となるためである。2050年ネットゼロに向けて直線的な排出削減を目指す現在の政府目標を達成するためには、排出削減が進む後期において、強力な対策を実施しなければならなくなると考えられる。対策の遅れによって2030年度以降の政府目標や2050年ネットゼロ目標を達成できなかったり、急激な対策強化により社会的コストが大幅に増加することを防ぐためには、一貫した長期的見通しに立って早めに必要な対策を導入していくことが重要であると考えられる。（discussion partでコストの議論?）

実績値は減少傾向が続いており、2023年度は2013年度に対して18%減少している。実績値を直線でフィットし将来に延長すると、1.5℃ロードマップのバランスシナリオと同程度のペースで減少が続いていることが分かる。また、エネ基で想定されている2030年度や2040年度のエネルギー消費量は、実績値の推移と比べると、大幅に大きいエネルギー消費量が設定されている。
全体としてのエネルギー消費量の低下がどのような要因でもたらされているかは、本節以降で部門ごとのエネルギー消費量や排出原単位の変化を踏まえて考察する。
なお、本稿で第7次エネ基（エネルギー需給見通し）での目標値・見通しを示す際には、2040年度のエネルギー起源CO2排出量が2013年度比約70%削減される4つのシナリオ（再エネ拡大、水素・新燃料活用・CCS活用・革新技術拡大）に加えて、エネルギー起源CO2排出量が2013年度比56%削減にとどまる（すなわち、政府目標が達成されない）「技術進展シナリオ」の値も示している（赤い三角形で表示）。「技術進展」シナリオは、参照されたRITEによる分析では「再エネ、CCS・CDR、水素系エネルギー、原子力等の技術進展・普及が抑制的」なシナリオと説明されており、「排出上振れリスクシナリオ」と呼称されている。本稿では実態により即した呼称として、RITEの説明資料を参照し、「排出上振れ」シナリオと記載する。

*図[elec_total]: 日本の最終エネルギー消費量における電力量の実績（灰色の点）。その他の点の定義は図[energy_total]と同様。左側の縦軸はEJ、右側の縦軸はTWhで表示*

図[elec_total]は、電力の消費量（最終エネルギー消費量における電力量）で同様の図を描いたものである。実績については、エネルギー全体と同様に、長期的に減少する傾向が続いているが、エネ基での需要見通しは、特に2040年度については、複数のシナリオのいずれにおいても、近年の実績値よりも大幅に大きい電力消費量が想定されている。エネ基では「デジタルトランスフォーメーション（DX）やグリーントランスフォーメーション（GX）の進展により、電力需要が増加に転じることが見込まれている」とされている。IGES 1.5℃ロードマップにおいても、（政府目標シナリオを含め）2040年は2030年に比べて電力消費量は増加するシナリオとなっている。エネルギー消費量全体が少なくなっていく中でも、デジタル化や電化の進展により、電力消費量は増加していくことが想定されている。

![排出原単位全体](doc/report2026/figures/20260226_11_plot_intensity_total_energy_cap.png)
*図[intensity_total]: 日本全体の排出原単位の実績（灰色の点）。その他の点の定義は図[energy_total]と同様*

図[intensity_total]では、エネルギー消費全体での排出原単位について、エネルギー消費量と同様に示している。ここで排出原単位は、総合エネルギー統計の最終エネルギー消費について、「総合計 / 電力･熱寄与間接排出配分後合計」エネルギー利用分CO2排出量をエネルギーの合計（エネルギー利用分）で除して計算した。
実績は2013年度をピークにその後減少しているが、下がり方は緩やかで、実績の直線フィットの延長と1.5℃ロードマップでの2030年以降の排出原単位の推移やエネ基での見通しを比べると、排出削減目標を達成するためには、排出原単位をこれまでよりも速やかに下げていくことが必要であることが分かる。

*図[intensity_elec_total]: 日本全体の電力の排出原単位の実績（灰色の点）。その他の点の定義は図[energy_total]と同様*

図[intensity_elec_total]では電力部門での排出原単位について、図[intensity_total]と同様に示した。図[intensity_total]と図[intensity_elec_total]は縦軸のスケールが揃えてある。石炭、天然ガスによる火力発電が電源の多数を占めている現状では、発電に伴うエネルギーロスにより、電力の原単位はエネルギー全体に比べて大きいが、2013年度以降は主に再エネの拡大によって、原単位の減少ペースはエネルギー全体よりも早い。しかし、2014年度以降の実績を直線でフィットした結果の延長と比較すると、エネルギー全体の排出原単位と同様に、1.5℃ロードマップでの2030年以降の推移やエネ基での2030年度、2040年度の見通しに比べると十分なペースではなく、電力の脱炭素化を加速することが必要であることが分かる。
なお、（後で見るように）第7次エネ基の想定では、1.5℃ロードマップ（バランスシナリオ）と比べると、2040年時点での再エネの設備容量は大幅に小さいが、第7次エネ基の複数のシナリオの一部では、1.5℃ロードマップよりも電力の排出原単位が小さいケースがある。これは、CCS貯留の社会的障壁が小さく、火力発電からのCO2がほぼ全てCCSによって回収されるシナリオとなっている。

#### 対策強化とコスト

[日比野ほか(2025)][Hibino2025]での分析: 
- 技術進展シナリオ、革新技術シナリオ、社会変容シナリオを用いて排出経路を検討
- 技術進展シナリオは2030年以降排出量が上振れする。2050年ネットゼロにたどり着くためには、急激に革新的技術を導入する想定となり、設備更新のタイミングを待たない機器の導入や新燃料への依存の増大で、脱炭素技術導入のコストが増大する
- 革新技術シナリオや社会変容シナリオは直線的な排出削減で2050年ネットゼロとなるシナリオで、どちらも脱炭素技術導入のコストは2040年代に増加している
- デジタル化・循環経済の進展等による行動変容を織り込んだ社会変容シナリオでは、脱炭素技術導入の累積コストが革新技術シナリオに対し低減される
- 一方で、社会変容シナリオで再エネ・新燃料・電化を加速した場合、技術習熟が十分でない段階で大量導入することに伴うコスト増大が発生することが示されている
